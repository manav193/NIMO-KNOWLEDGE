# Project Contract: NIMO-WEB

> **Status**: Future Integration Specification

NIMO-WEB is the primary web application and student study interface for the NIMO ecosystem.

## Future Interactions
- **Consumes**: `faq/approved/` items for instant student help and `knowledge/education/` for conversational scaffolding.
- **Emits**:
  - User feedback (`feedback.schema.json`)
  - Feature requests (`feature-request.schema.json`)
  - Frequently asked questions (`faq.schema.json`)
  - Client-side error patterns (`issue-pattern.schema.json`)
